# 🐾 Mypet

Plugin profesional de mascotas para Paper 26.2

## 👤 Autor
**soyadrianyt001**

## 📌 Versión
1.0

## 🎮 Comandos
- `/mypet create <mob> <nombre>` — Crear mascota
- `/mypet gui` — Abrir panel de control
- `/mypet remove` — Eliminar mascota
- `/mypet rename <nombre>` — Renombrar mascota
- `/mypet creator` — Info del plugin
- `/mypet help` — Ayuda

## ✨ Características
- Sistema de mascotas completo
- GUI profesional
- Anuncios automáticos configurables
- Mascotas que siguen al dueño
- Anti-bug con teletransporte
- Sonidos configurables
